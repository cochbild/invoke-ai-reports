# Support

## How to get help

- **Bug reports:** open a [bug report issue](.github/ISSUE_TEMPLATE/bug_report.md).
- **Feature requests:** open a [feature request issue](.github/ISSUE_TEMPLATE/feature_request.md).
- **Questions / discussion:** open a regular GitHub issue with the `question` label.
- **Security vulnerabilities:** see [SECURITY.md](SECURITY.md) — do not open a public issue.

## Before opening an issue

- Check existing issues (open and closed) — your question may already be answered.
- Make sure you are on the latest `main`.
- For setup issues, include OS, Python version, Node version, and the exact command that failed.
- For data issues, include the output of `GET /api/sync/status` (redact paths if sensitive).

## Response time

This is a personal side project maintained on a best-effort basis — no response or resolution timelines are promised. Issues may sit untouched for a while; pull requests with tests are the fastest path to a fix.
